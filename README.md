# Essence Royale

Boutique de parfums en ligne en français, avec catalogue, filtres, panier et parcours de commande responsive.

## Paiements

Wave et Orange Money sont présentés en mode démonstration. Pour accepter de vrais paiements, il faut relier le site à un serveur sécurisé et aux API marchandes officielles correspondantes. Les clés secrètes ne doivent jamais être placées dans le code du navigateur.
